# 去掉 Redis，聊天实时状态统一使用 PostgreSQL

> 2026-11-22 部分替代：[情侣共享与整体重构](2026-11-22-情侣共享与整体重构.md)将 PG 表、LISTEN/NOTIFY、数据库时钟和锁机制替换为 SQLite `chat_events` / `leases`、应用 Clock 和进程内事件总线。不重新引入 Redis；持久事件、提交后唤醒、断线恢复、取消/可见长度、取代和尾部终态补齐语义保留。游标/恢复世代改按 host 定义。以下为历史实现记录；R0 尚未迁移代码。

个人电脑运行后端不再启动 Redis。迁移 0022 新增聊天事件、临时控制和会话锁表；事件使用轮次内递增序号，SSE 游标为不透明的 `pg-序号`。旧游标、未知游标和过期事件仍通过业务表恢复快照或原有缺流响应。

事件写入与通知在同一事务提交。每个进程通过 postgres.js 在独立连接监听固定频道，载荷区分轮次和会话；取消与释放锁立即唤醒订阅者，断线由一秒轮询兜底。读取空批后见到业务终态时再次读取剩余事件，再补发结束标记。

终态事件保留十分钟，非终态保留一小时（均从最后事件计算）。读取时过滤过期数据，已有清扫器定期删除。取消与可见长度各自保留十分钟；作废优先于停止。会话锁使用数据库时间、三十秒租期和持有者令牌，过期可接管，只有当前未过期持有者可续租。

健康检查只检查数据库。部署与本机开发只需 PostgreSQL；历史验收记录保留当时环境，不作追改。
