# 宿主双模型分工 · 2026-11-19

## 已定

1. macOS 宿主允许同时保存本地模型与 DeepSeek key，不提供互斥模式开关；保存任一来源后重新计算配置、重启 API 和 worker，不删除另一来源。
2. 两者齐全时，写 `MODEL_PROVIDER=openai-compatible`、`OPENAI_COMPAT_MODEL`、`OPENAI_COMPAT_BASE_URL`（保留现值，缺省为 `http://127.0.0.1:11434/v1`）与 `MAOMAO_DEEPSEEK_API_KEY`，将 `CHAT_PROVIDER`、`ROUTER_PROVIDER`、`WORKER_PROVIDER` 设为 `deepseek`。EXTRACT 默认继承本地来源，覆盖记忆提取、边界摘要及模型辅助回忆。
3. 只有本地模型时全局默认本地，只有 key 时全局默认 DeepSeek；两种保存操作均清除 CHAT/ROUTER/WORKER 原有 provider 覆盖，防止分工残留。宿主不修改任何槽位的 `*_MODEL`、`EXTRACT_PROVIDER`、思考或并发参数，用户显式覆盖继续优先。
4. 菜单分别显示两个来源的状态、实际角色及全局默认；只要配置了本地模型便轮询其端点。端点可达不等于推理通过，保存 key 不等于远程鉴权通过。不内置密钥，不将模型配置作为 API/worker 启动门槛。

实现与配置说明见 [macOS 宿主](../../desktop/macos/README.md)。
