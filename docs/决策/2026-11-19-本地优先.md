# 本地优先 · 2026-11-19

## 已定

1. 猫猫 App 跑在**用户自己的个人电脑**上，与 [linger](https://github.com/simplexai-labs/linger) 的定位相同：API、worker、数据库与（可选的）本地模型都在这台电脑上运行，手机 App 连这台电脑。我们不运营面向公众的托管服务。
2. 推翻 [2026-11-10 异步Agent](2026-11-10-异步Agent.md) 第 2 条“部署地点与时间……届时再定具体云与合规手续”，以及[异步 Agent 方案](../方案/团子异步Agent与后端架构-方案-2026-11-10.md)第五段中“测试环境部署（托管 PG / Redis、HTTPS 域名）”和评审点 2。第五段里与部署位置无关的部分（推送收据语义、发布前复核、每日预算）继续有效。
3. [`server/deploy/`](../../server/deploy/README.md) 的云测试部署包不再是目标；本机隔离验收与回退演练脚本先保留，等电脑端打包落地后，由打包那一批决定删除或改写。
4. 一台电脑上一个安装、一个主人、一只猫。多账号、跨用户隔离不再是设计目标，但现有的权限、边界、记忆许可、预算和发布前复核全部保留。

## 方案批准

用户批准[本地优先架构重塑方案](../方案/本地优先架构重塑-方案-2026-11-19.md)，第 4 节评审点按推荐值执行：

1. 推送：先不做远程推送；手机拿到约定时间时排本机通知，打开 App 时拉取信箱。APNs 中继另行决策。
2. 远程访问：先只支持局域网；不在家时显示“团子在家里的电脑上”。
3. 平台：电脑端先只做 macOS。
4. 数据库：保留 PostgreSQL，随宿主打包，不换 SQLite。
5. 默认模型来源：安装时按硬件推荐本地模型，不够时引导填自带的 DeepSeek key；不内置开发者 key。
6. `server/deploy/`：F 批落地时删除云 staging 部分，本机验收部分并入宿主测试。
