# 宿主恢复与日记同步 · 2026-11-21

- 恢复前暂停 API 与 worker，再备份数据库和宿主配置。安装备份或重新启动失败时，尝试恢复操作前的备份。自动回退也失败时保留备份，并显示失败原因与备份名称。
- 日记增量游标只在同一同步世代有效。宿主在替换备份后更新世代，世代随宿主数据持久保存，独立于备份。新版 iOS 收到重置响应后从头读取，保留手机未上传的内容与待同步的撤回，过期的分享操作须重新授权。服务端拒绝显式携带旧世代的写入。
- 宿主使用本机 CA 检查实际的 HTTPS 端口。worker 菜单状态来自最近一次本进程的队列恢复检查，其中已到期超过五分钟的待办会提示积压。
