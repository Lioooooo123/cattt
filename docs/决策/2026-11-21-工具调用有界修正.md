# 工具调用有界修正

前台与托付循环可选择一次性修正未知工具名或对象参数校验失败。先对整批调用做原子预检；失败时不执行任何调用，以配对的失败观察和有限结构诊断进入下一普通模型步骤。重复调用、截断或异常结束、取消、权限变化及持久化／执行错误仍按严格失败处理。前台每轮最多拒绝一批，托付额度记入现有步骤用量检查点，跨进程续跑不重置；工具预算与权限规则不变。

该范围仅借鉴 Linger 的集中式、有界调度思路：[model-scheduling.md](https://github.com/simplexai-labs/linger/blob/main/docs/model-scheduling.md)。Linger 使用带额外托管服务与前端标识条件的修改版 Apache 2.0 许可证（[LICENSE](https://github.com/simplexai-labs/linger/blob/main/LICENSE)）；这里只记录架构参考，不复制代码或 UI。
