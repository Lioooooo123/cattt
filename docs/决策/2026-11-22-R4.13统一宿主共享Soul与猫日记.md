# R4.13 统一宿主共享 Soul 与猫日记

在 R8.18 的迁移 0024 之后追加 `0025_r4_shared_soul_diary`。沿用 R4.9 的共享 Soul 投影、猫日记日历、来源卡、计算和出版队列。原有个人日记接续、成员资源行为、小院在场和模型角色继续走各自既有入口。

Peer 协议升至 8。已配对宿主保留证书、指纹、成员和复制水位。两台升级后用现有管理结对接口重新确认。共享事实写入继续使用群聊发布凭据，日记收据随 `cat_fact` 复制并纳入租约交接摘要。

猫日记计算仅用 `extract` 本机模型或受控 mock，使用宿主 UTC 日账本及共享准入队列。缺本机模型的计划保持待恢复。超额或输出无效时可以发布安静模板。日期计划 ID 作为稳定操作标识，作业认领与来源在模型派发前及出版时分别核对。已经出版和复制的日记可随来源许可撤回而重新渲染，保持原日记 ID。

接口、重连步骤和默认模型接缝见 [API v2 共享 Soul 与猫日记](../参考/API-v2-共享Soul与猫日记.md)。
