# R4.17 猫日记感受选择

默认真实本机模型为猫日记选择一种内心感受，以及最多四条已审核事实卡。宿主用所选感受生成团子的第一人称短句，地点和带署名的引文从审核卡渲染。`writer` 记录提供选择的模型。

R9.7 实测发现模型有时会颠倒已审核卡片的顺序。四张以内由请求 schema 约束短编号沿输入顺序全部保留，超过四张仍由模型选卡，宿主按审核顺序渲染通过校验的引用。

沿用共享猫日记的准入、预算、租约和出版收据。模型见过的卡片不可用时，读取投影替换原感受、移除失效引用，沿用原日记 ID 和归档日期。详见 [共享猫日记契约](../参考/API-v2-共享Soul与猫日记.md#模型与预算)。
