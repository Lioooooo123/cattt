# R4.9 共享 Soul 与猫日记 · 2026-11-22

R4.9 接在 R8.14 世界宿主和 R9.1 一次性导入之后，由同一群聊租约控制共享 Soul、日记日历和每日猫日记发布。

- 团子底色沿用既有 Soul。明确习惯沿用回复长短、建议方式和猫咪表达三项。临时精力与活动意愿最多持续一天。称呼和熟悉程度按提出它的成员保存。单聊只提供该成员的相处信息，群聊逐人标记。新调整使用本人有效的指定消息修订，经明确确认写入。撤回、失效或到期后回到默认值。被替代的旧设定不会自动复活。小院状态读同一份 Soul，现有场景动作继续由世界协议确认。
- 每只团子使用一份共享日历，首选首成员已保存的时区，默认 `Asia/Shanghai`。首次启用从当天起记录。当地 D+1 日 00:05 后生成 D 日记，一天一个稳定归档日期和确定的 UTC 区间。改时区影响今后的待建日期，已有日期和观察标签保留。时钟作业可在重启或接任发布后续办已登记的缺日。
- 日记只使用有效 3D 观察证明的地点，或由成员本人确认且仍许可的聊天、日记修订。地点观察来自已鉴权状态上报或确认到达，可运行、未暂停且处于静止或交互。用户原话以具名引文显示。猫的感受段与来源卡片分别保存。期满日期的当前世界快照、天气、水碗、在场和动作完成均不能补写成历史。
- 模型只走明确配置的本机 extract 或受控 mock，按 `cat_diary` 用途接 R4.8 准入与预算。硬门先筛选事实，写作仅挑选事实卡，内心短记沿用长度和具体经历校验。模型缺席、额度拒绝或输出无效时使用既有的安静日常文案。出处撤回时去掉受影响的引文，并替换曾读到该素材的模型感受段。每日猫日记、游客访问和日记撤回均无主动推送副作用。
- 每次共享事实写入复核捕获的群聊发布凭据。跨机复制传事实、日记收据和来源修订及摘要。计算只交本机持久草稿，Router 复核后出版。接任前校验旧发布历史摘要，导入或重放已出版记录不会重跑模型。
- 旧猫日记保留原日期、时区和正文，以 `legacy` 标记。旧 Soul 只投影能够关联本人有效来源的最新明确习惯，以及能同时核对状态与事件且仍未过期的临时状态。旧版本原文、无来源条目、历史状态快照和执行留在 R9.1 审计证据里。正常视图提供旧版本号、映射结果和源哈希，早期副本等待拥有旧归档的发布宿主完成检查。

迁移、HTTP 和模型接缝见 [API v2 共享 Soul 与猫日记](../参考/API-v2-共享Soul与猫日记.md)。
