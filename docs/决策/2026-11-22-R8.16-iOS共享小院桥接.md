# R8.16 iOS 共享小院桥接

iOS v2 配对复用钥匙串、固定 CA 与身份核对。首次打开注册院子会话，短暂断线和前后台切换复用同一会话。宿主重启或会话被替换时重新注册一次。再次被替换时，由成员点「重新连接小院」恢复。其他成员的短时在场只来自宿主，连接断开时清除。

首次 3D 画面从 GET /state、注册响应或原子落盘的成员增量初始化。视图按宿主确认的当前位置、时段、天气和水碗投影。陪坐只在已有可信坐姿时恢复该姿态。副本与等待发布权时保留可浏览的小院和信箱，等待当前世界中的新观察。已有成员增量缓存升级时仍可离线读取，首次成功联网拉取从初始页补收世界记录。

写入宿主的会话先以已应用的 revision 争取控制。预期的写入冲突重新读取共享状态，活跃执行会话继续驱动。收到宿主 SSE 动作后，先用原版本回传 accepted，等待宿主确认，再由现有 3D 执行。陪坐需实际落座并达到非降级的 `sit_idle`。断线期间保留原时间、原快照和动作 ID 的在途回执。页面重载以共享投影恢复，原 3D 行程终止。界面只按宿主回执宣布动作结果。v1 与本机模式沿用各自入口。

## Mac 共用的 3D 接缝

继续使用带 `runId` 和 `pageId` 的 `window.__app.command`。首次 `initialize` 使用 `sharedWorld` 字段，内容是 `{type:"sharedWorld",intent:{type:"intent",id,place,activity},slot,weather,full}`。后续可发送同结构的 `sharedWorld` 命令。投影意图的 `activity` 为 `watch` 或已确认的 `sit`，`place` 取业务快照的当前位置。原生收到宿主确认的 accepted 后，通过常规 `intent` 命令执行，监听匹配该意图 ID 的 `cat` 事件。现有信箱仍由射线命中后发出 `tap` 事件。

本轮复用现有团子模型和地点级业务快照。更细的跨设备坐标、场景外观及动态 Soul 仍由单独契约和验收决定。
