# R8.17 旧手机日记接续

- 旧账号以钥匙串里的 v1 配对为准。首次连接 v2 时，只有当前家庭、家用宿主和成员与 R9.1 导入收据一致，且旧账号 ID 匹配，手机才读取配对日记文件。没有凭据、没有对应收据或账号不符时保留原档案。原本地模拟空间、开发模式和无法表示的旧记录留在原文件。
- 已同步的旧记录由 v2 增量读取。手机把未送达的文字草稿和待处理权限操作与接续标记一次原子写入当前设备的资源队列。离线重启后继续原请求，原 v1 记录保留供回退。缺失可选同步字段沿用 v1 含义，已知云端 ID 且待提交私密权限视为待撤回，已有私密确认则只对齐。
- 按旧云端 ID 和客户端 ID 核对 PG 导入记录。丢失 v1 回执的草稿以客户端 ID 对齐。已有记录继续使用宿主的正文、日期、许可和墓碑。待撤回只关闭团子读取许可，先前待授权的操作由成员在日记中重新确认。手机独有的草稿保持原当地日期、时区 ID 与阅读开关。
- 接续复用资源收据、日记事务和成员增量游标。宿主写入后回包丢失时，同键返回当前投影；后来变更权限或删除记录后，重放旧请求仍保留当前状态。

协议见 [API v2 成员资源契约](../参考/API-v2-成员资源契约.md#r817-旧手机日记接续)。
