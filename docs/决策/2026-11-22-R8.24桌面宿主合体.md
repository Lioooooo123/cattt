# R8.24 桌面宿主合体

已在独立工作树接入，待 R9 汇总。

- Bun 桌面成品默认编译本仓库的 `host/`。桌面管理走回环，设备业务走固定 CA 的 HTTPS，宿主复制独立走 mTLS。包内 3D 小院使用 R8.18 已接入的 Web 桥，与 iOS 共用资源。
- 接入 R8.11 备份恢复、Swift 监督器和 R8.20 管理契约。恢复验证期间开放健康检查与回环状态，暂停业务接口和 peer 拉取。mTLS 的维护响应带当前 peer 协议版本。通过恢复后，旧成员同步游标要求重拉，旧轮次 SSE 游标收到快照。
- 桌面和 iOS 都等网页的 `ready` 消息再发初始化。桌面读取命令返回结果，并保留 WebKit 返回的错误。后台测试窗口的页面不可见时，保留诊断；移动和陪坐的固定帧烟测只验证命令到回执链路。
- 迁移链保留 R8.18 的 0000–0024 及原有快照、journal 和嵌入清单。R8.24 无 schema 迁移。R9 合体如引入 R4.13，应以 0024 快照为父级接续 0025，并在全部 schema 改动确定后更新 journal、快照和嵌入清单，核对 0000–0024 的 SQL 及快照原件；本批无需占用后续编号。

构建和烟测入口见 [macOS 宿主](../../desktop/macos/README.md#bun-成品与共享小院)。
