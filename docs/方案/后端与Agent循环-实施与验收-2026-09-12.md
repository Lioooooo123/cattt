## 已实施范围

### 后端可靠性

- `turns/store.ts` 统一认领、首字资格与终态事务。并发完成/失败/停止只能有一个结果；猫回复有 turn 唯一索引。
- 完成/停止与记忆待办同事务，边界与整理待办同事务。PG 保存待办，BullMQ 执行；进程扫描不依赖 Redis scheduler 是否存在。
- 重试最多三次，租约到期可恢复；同来源重新回复共享固定提取结果和完成标记。历史缺失待办通过显式 `backfillJobs()` 补建，启动不自动批量调用真实模型。
- 记忆写入和删除共用猫锁；凭证防重复处理，来源顺序防旧偏好覆盖新偏好，删除后的旧 explicit 来源不能解除阻断。
- Redis 发布检查每条命令错误。仅终止事件缺失时从 PG 补终态；发布失败不覆盖已完成业务结果。
- HTTP 路由按猫、聊天、记忆、边界、Soul、世界拆开。模型模块不再依赖 BullMQ 的错误类型；队列连接按需建立。

### Agent 循环与世界

- 使用已安装的 `ai@7.0.97` 模型工具循环；最多四次模型请求、六次工具执行（含 finish_tools）、一个世界动作，整轮 45 秒。SDK 自动重试关闭，失败沿用用户重试协议。
- 工具顺序执行，调用先入账再执行；记录每步耗时、结束原因、用量与工具结果，不保存隐藏思考。
- 开放 get_time、get_world_state、get_action_status、get_weather；可执行的新鲜世界 session 才开放 move_cat。
- 世界会话/快照/命令回执独立于聊天 SSE；只接受当前猫和当前会话代次，按语义版本与 actionId 去重。同一来源消息重答不会再次移动。
- iOS 复用 WorldEngine.request 的路线与出窝流程；手动操作优先，暂停中断归属。停止文字取消未接收命令；已接收动作保留真实进展。
- 前台聊天与小院都可推进世界并接受动作，镜头帧只在小院更新；后台、首次引导和手动暂停仍停止世界。未实现离线自主生活。

### 审查后修复与天气接入

- SSE 在确认 PG 终态后非阻塞读完剩余事件，再补结束标记。回归覆盖“空读后才写入最后 delta”的交错，不会漏尾字。
- 新迁移 `0004_memory_block_watermark.sql` 为旧 `source_seq=0` 阻断回填该猫迁移时消息水位。旧 explicit 消息不能解除历史删除，新消息仍可明确要求记住。采用新迁移，不修改已执行的迁移。
- 普通 Redis 请求和 BullMQ 投递有界失败；消费者保留重连。故障生产连接销毁并在下次补投重建。队列补投与 PG stale 清理各自防重入，投递故障不再阻塞清理；清理的事件发布失败不影响已提交终态或其他轮次。
- iOS 回执保存事件时快照与同步服务器时间，重连不拿当前地点替代；accepted 响应不确定时先按原请求恢复事实，再决定执行或中断。
- 历史执行回执可推进动作账本，不回退较新世界观察。仅 execution_timeout 允许补截止时间前到达的设备证据；取消、抢占和旧会话不能复活。设备时间来自服务器同步钟加 uptime，是客户端执行证据，不是服务端独立观测。回执在本进程保存，重启仍创建新会话。
- 天气接入 Open-Meteo：显式城市、重名消歧、当前天气/当地日期预报；总 3 秒超时，地理结果缓存 24 小时、天气 10 分钟，每类最多 256 项。缓存保留原始数据时间；无字段不补造，失败不伪报成功。current 标为模型当前估算，forecast 标为预报，均附来源、单位和数据时刻。
- [Open-Meteo 天气 API](https://open-meteo.com/en/docs)、[地理 API](https://open-meteo.com/en/docs/geocoding-api)、[条款](https://open-meteo.com/en/terms)：公共免费端点用于本机非商业开发；商业服务需采用符合供应商条款的方案。输出带 Open-Meteo / GeoNames 归属，不改变院子视觉天气。

### 团子、Soul 与临时状态

- 团子的外在克制、内心细腻、自然“喵”和猫咪细节进入 persona；不承诺尚未实现的定时来访。
- 每猫独立 Soul 与基础性格版本，轮次保存所用版本和状态；成长正文与结构化条目同版本生成。
- `GET /v1/cat/soul` 读取；`POST /v1/cat/soul` 根据明确来源调整回复长度、建议方式或猫咪表达；`DELETE /v1/cat/soul/:id` 撤回。当前是开发者 API，没有新增用户页面。
- `PUT /v1/cat/state` 设置有来源、有期限的精力/活动意愿。重复来源不重复应用，到期回基线；聊天注入同一状态，小院收到 runtime_state 后调整自发游走，明确移动指令仍可执行。
- 删除或撤回来源会清理派生成长及相关历史正文；当前生成检测到边界或档案变化后停止旧上下文输出。

## 使用与迁移

升级其它尚未迁移的库时，先停止旧 API/worker，检查 cat 消息是否有重复 turn，再执行 `cd server && pnpm db:migrate`，随后重启 API/worker。迁移 0002–0004 为增量，不删除旧数据；唯一索引遇到历史重复会失败，需要先检查，不自动删除记录。新 worker 与新写入端应一起启用。

回退代码时保留新增表和数据，停止新 worker，不通过删表回退。2026-09-12 本机 maomao 开发库已迁移至 0004（共 5 条迁移）；升级前重复猫回复 0 条、旧阻断 0 条。原有服务未运行，无需强停用户进程。验证服务已结束，后续用 `cd server && pnpm dev` 正常启动。
