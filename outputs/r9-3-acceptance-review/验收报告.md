## 复跑命令

使用 Bun 1.4.5。依赖按 `host/bun.lock` 和 `web/pnpm-lock.yaml` 安装，`PATH` 包含 PostgreSQL 17 的 `initdb`、`pg_ctl`、`psql` 和指定版本的 Bun。Mac 烟测串行使用临时数据目录、内置 mock 与 `127.0.0.1` 上的聊天工具协议桩。

```sh
(cd host && CATTT_TEST_PG=1 bun --no-env-file test --max-concurrency 1)
(cd host && bun run typecheck)
pnpm --dir web test:app
pnpm --dir web build
python3 tools/check_shared_rules.py
bash desktop/macos/scripts/build-bun-app.sh
APP="$PWD/desktop/macos/build/CatttBunHost.app"
codesign --verify --deep --strict "$APP"
CATTT_R85_TEST_APP="$APP" swift test --package-path desktop/macos
CATTT_BUN_APP="$APP" python3 desktop/macos/scripts/smoke-bun-host.py
CATTT_BUN_APP="$APP" python3 desktop/macos/scripts/smoke-bun-backup.py
CATTT_BUN_APP="$APP" python3 desktop/macos/scripts/smoke-bun-yard.py --fixture-renderer --chat-actions --skip-build
```
